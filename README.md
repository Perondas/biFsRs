# biFsRs

`bi_fs_rs` is a Rust library for reading, writing, and parsing [Arma](https://arma3.com/) related file formats.

## Features

* **PBO Operations:** Read, extract, and manipulate PBO (Packed Bohemia Object) archives.
* **Signatures:** Support for parsing and creating Arma signature files (`.bisign`).
* **Keys:** Handle Arma server keys (`.bikey`).
